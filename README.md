  # 💧 Watermark Studio PRO
  
  **Batch image watermarking made easy.**  
  A fast, lightweight, and native Windows desktop application for bulk watermarking images.
  
</div>

---

## 🚀 Features

- **Batch Processing:** Watermark hundreds or thousands of images (JPG, JPEG, PNG) in seconds using high-quality bicubic interpolation.
- **Subfolder Support:** Recursively process images deep within nested folders.
- **Flexible Positioning:** Place your watermark in any corner (Top Left, Top Right, Bottom Left, Bottom Right).
- **Dynamic Scaling:** Watermarks automatically scale relative to the target image size (20% of the image width) for consistent branding.
- **Auto-Updater:** Built-in seamless OTA (Over-The-Air) update checker that safely downloads and installs new versions directly from GitHub Releases.
- **Tiny & Native:** Built with C# and .NET 8 Windows Forms, compiled into a tiny, lightning-fast standalone `.exe`.

## 📥 Download & Installation

1. Go to the Releases page.
2. Download the latest `https://github.com/loveonce/Watermark-Studio-PRO/blob/main/WatermarkStudioPRO.exe`.
3. Double-click to run! *(No installation required)*

*Note: If you don't have the .NET 8 Desktop Runtime installed, Windows will prompt you to download it automatically upon first launch.*

## 🛠️ How to Use

1. **Add your Watermarks:** Click **Add New** to import your transparent `.png` logos. They will be saved to a local `watermarks` folder next to the app.
2. **Select Input Folder:** Choose the folder containing the images you want to watermark. Check *Include subfolders* if necessary.
3. **Configure Options:** Select your preferred watermark and its position on the image.
4. **Select Output Folder:** Choose where the processed images should be saved, or check *Replace original images* to overwrite them.
5. **Click Start:** Sit back and let the app do the heavy lifting!
